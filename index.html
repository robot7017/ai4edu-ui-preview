01问题实验室 · The lab

一间实验室，一位老师，六张台。

这是一节 PCR 实验课。每张台做到不同的步骤，老师只能站在一张台旁边；某一步做错，往往要等结果出来才发现。先看 B 台出了什么错，再回到课前，看 LabMate 怎么一路帮他。

  1. 六张台，进度各不相同
  2. 老师在 A 台，顾不上其他台
  3. B 台出错了，没人发现
  4. 错在哪：移液量设错，试剂也拿错了
  5. 回到课前：B 台的同学先在平板上准备

从一个问题开始。

回到课前。B 台的同学先在平板上选一个感兴趣的小场景，在 Dr. Pipette 引导下自己搭出 PCR 方案，弄清每一步为什么这样做。

  1. 选一个小场景
  2. 说清你的问题

03课前仪器使用 · Instrument use

先会用仪器，再做完整实验。

还是在课前：一步步练会微量移液器，量程、握法、两档力度都练熟，再进实验室。

  1. 选择移液枪
  2. 调整量程
  3. 正确握持
  4. 感受两档力度
  5. 安装枪头
  6. 吸液准备与吸取

戴上眼镜，走到实验台。

识别效果

看懂实验过程，而不只是认出器材。

提示要有用，眼镜得知道学生正在做哪一步、做得对不对。

同一帧画面：移液器的按钮按到了第几档？按钮有两个档：按到第一档吸液，按到第二档把液体排净；不按是 0 档。这一帧的正确答案是 0 档。

  1. 通用视觉大模型8.9%

    直接给出答案，不说明看的是画面哪里。

  2. 传统图像方法55.6%

    答案碰巧对了：它把枪头和枪头盒当成了按钮，真正的按钮没找到。换个角度、换个光线，就容易判错。

  3. LabMate75.6%

    先找准按钮、针尖和手的位置，再判断档位。

百分比为同一批测试画面上判断档位的准确率；三栏使用同样的画面。

  1. 读得懂

    读出读数，判断对错

    能读出移液器等器材上的读数，并和这一步的要求对照。调错了当场提醒，不用等老师走过来。

  2. 跟得上

    知道学生做到哪一步

    按实验流程跟着每一步走。漏做、顺序不对都会提示，老师端同步看到每张台的进度。

  3. 认得出

    戴手套、有遮挡也认得出

    实验室里手套、反光和器材遮挡很常见。戴着手套操作，也能稳定认出手和器材。

五类课堂，都需要看见实验过程。

首个计划试点课程为港科大（广州）UFUG 1403 PCR 实验；十余名参与者已试用原型。下面是我们面向的五类课堂。

  1. 新型及国际化大学

    • 通专融合、跨学科实践
    • 非专业学生实验能力
    • AI 教育示范、过程评价
    首个计划试点港科大（广州）UFUG 1403 PCR 实验

    通识实验课，学生专业背景各异，需要在课上就把操作做对。

  2. 普通高中

    • 理化生学生必做实验
    • 大班分组实验，一位老师照看全班
    • 实验操作考查、过程性评价
    典型场景高中理化生分组实验课

    全班分组同时做实验，老师很难逐组检查操作是否规范。

  3. 职业院校与技工教育

    • 高比例实践、标准操作训练
    • 实训过程考核、多人并发
    • 教学与考试一体化
    典型场景医药类专业的实训课

    多人同时实操、按标准流程考核，需要记下每个人的操作过程。

  4. 国际化学校 / 国际课程学校

    • AP / IB / A-Level / DSE 理化生实验技能
    • 双语实验指导与过程评价
    • STEM 项目、竞赛与升学展示
    典型场景中学 STEAM 与理化生实验课

    双语授课，实验技能计入课程评价，需要过程记录与及时反馈。

  5. 职业技能培训与实操评价

    • 标准化培训、上岗前考核
    • 过程证据留痕、评分一致性
    • 教学 / 考试模式切换
    典型场景技能竞赛与上岗考核
